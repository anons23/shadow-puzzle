# Тени

Головоломка для Android: вращай предмет на столе, пока его тень на стене не совпадёт с контуром.

## Как устроено
- `js/engine.js` — 3D-предметы (13 шаблонов из коробок, призм и конусов), вращение, проекция тени и сравнение теней по IoU.
- `js/levels.js` — 20 уровней. Каждый строится вокруг секретного положения, поэтому всегда решаем. При генерации проверяется, что допуск по углу достаточно широкий для пальца. С 14-го уровня предметы идут парами.
- `js/main.js` — экраны, вращение пальцем (кнопки ◀▲▼▶ для точной подстройки), звук, прогресс (localStorage).
- `js/ads.js` — реклама. В браузере заглушка, на телефоне использует плагин `OneTouchAds` (`showRewarded`, `showInterstitial`).
- Подсказка за рекламу показывает на столе нужное положение предмета.

## Запуск и проверка
```
python3 -m http.server 8080      # открыть http://localhost:8080
node tools/check-levels.mjs      # проверка всех уровней
```

## Сборка APK
```
npm install
npm run prepare-web              # копирует в www только игру, без ключей
npx cap add android              # один раз
npx cap sync android
```
Ключ подписи (.jks) в репозиторий и в www не кладём.
