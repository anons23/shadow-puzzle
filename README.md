# Тени

> Ветка `yandex-games` — версия для Яндекс Игр. Отличия от `main`: подключён `/sdk.js`, все уровни закрыты (`TEST_UNLOCK_ALL = false`), есть сборка архива.

## Загрузка в Яндекс Игры
```
python3 tools/build_yandex.py        # создаёт dist/shadows-yandex.zip
```
В архиве только игра (index.html в корне, css, js), без инструментов и конфигов Android.
Консоль: https://games.yandex.ru/console → «Добавить приложение» → загрузить архив во вкладке «Черновик».

Что уже сделано под требования:
- SDK из `/sdk.js`, `LoadingAPI.ready()` после загрузки меню (Game Ready).
- `GameplayAPI.start/stop`: старт уровня / победа, меню, реклама, уход со вкладки.
- Реклама только через SDK: подсказка за награду, полноэкранная после победы каждый 3-й уровень.
- Звук и музыка выключаются при уходе со вкладки и во время рекламы.
- Язык из SDK (`environment.i18n.lang`): русский или английский.
- Прогресс сохраняется в облако Яндекса (`player.setData`) и локально.
- Нет внешних ссылок, контекстное меню и выделение отключены, управление с клавиатуры на ПК.

Что нужно сделать в консоли самому: иконка 512×512, обложка 800×470, скриншоты, описание на русском и английском, возрастной рейтинг.

Головоломка для Android: вращай предмет на столе, пока его тень на стене не совпадёт с контуром.

## Как устроено
- `js/engine.js` — 3D-предметы (19 шаблонов из коробок, призм и конусов), вращение по трём осям, проекция тени и сравнение теней по IoU.
- `js/levels-data.js` — 60 готовых уровней. Создаются скриптом `tools/generate-levels.mjs`, в игре ничего не генерируется.
- `js/levels.js` — загрузка уровня из данных.
- `js/main.js` — экраны, вращение пальцем, кнопки ◀▲▼▶, ползунок наклона, звук, прогресс (localStorage).
- `js/platform.js` — платформа: сама определяет Яндекс Игры / Android / браузер. Реклама, сохранения (на Яндексе ещё и в облако), Game Ready и разметка геймплея.
- `js/ads.js` — реклама для Android (плагин `OneTouchAds`) и заглушка в браузере.
- `js/i18n.js` — русский и английский, язык выбирается автоматически.

## Оформление
- Одна сцена: стена, деревянный стол, свеча. Тень мягкая и слегка дрожит от огня, предметы объёмные с освещением, в луче летают пылинки.
- При совпадении контур вспыхивает и разлетаются искры.
- Каждые 15 уровней новая комната: Чердак, Детская, Театр, Мастерская.
- Анимация идёт ~30 кадров/с и останавливается, когда игра свёрнута.

## Звук
- `js/audio.js` — весь звук генерируется кодом (Web Audio), без файлов.
- Музыка: тихий эмбиент, у каждой комнаты свой лад; в Детской — музыкальная шкатулка.
- Атмосфера: треск свечи и фон комнаты (только на игровом экране).
- Отклик: шорох при вращении зависит от скорости, щелчки кнопок, тики ползунка каждые 5°, колокольчики при победе, звук подсказки.
- В меню отдельно «Звук» и «Музыка». Всё замолкает при сворачивании и во время рекламы.

## Рост сложности
- Уровни 1–7: один предмет, есть счётчик процентов совпадения.
- С 8-го: счётчик скрыт, подгонять надо на глаз.
- С 15-го: третья ось, ползунок «Наклон».
- 20–39: пары предметов, 40–60: тройки.
- Порог совпадения подбирается для каждого уровня так, чтобы допуск был 6° в начале и 3,5° в конце. Сложность растёт от формы, а не от пиксельной точности.

## Реклама
- За награду: подсказка.
- Полноэкранная: каждый 3-й пройденный уровень, сразу после победы и до окна с кнопками.

## Перед релизом
- В `js/main.js` поставить `TEST_UNLOCK_ALL = false` (сейчас для теста открыты все уровни).

## Запуск и проверка
```
python3 -m http.server 8080          # открыть http://localhost:8080
                                     # ?unlock=1 открывает все уровни для теста
node tools/generate-levels.mjs       # пересоздать уровни (около 40 с)
node tools/check-levels.mjs          # проверка: решаемость, допуск, случайные победы
```

## Сборка APK
```
npm install
npm run prepare-web              # копирует в www только игру, без ключей
npx cap add android              # один раз
npx cap sync android
```
Ключ подписи (.jks) в репозиторий и в www не кладём.
