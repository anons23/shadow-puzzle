# Тени

> Ветка `main` — версия для Android и RuStore (все уровни пока открыты для теста). Версия для Яндекс Игр с SDK, архивом и картинками для консоли — ветка `yandex-games`.

Головоломка для Android: вращай предмет на столе, пока его тень на стене не совпадёт с контуром.

## Как устроено
- `js/engine.js` — 3D-предметы (19 шаблонов из коробок, призм и конусов), вращение по трём осям, проекция тени и сравнение теней по IoU.
- `js/levels-data.js` — 60 готовых уровней. Создаются скриптом `tools/generate-levels.mjs`, в игре ничего не генерируется.
- `js/levels.js` — загрузка уровня из данных.
- `js/main.js` — экраны, вращение пальцем, кнопки ◀▲▼▶, ползунок наклона, звук, прогресс (localStorage).
- `js/platform.js` — платформа: сама определяет Яндекс Игры / Android / браузер. Реклама, сохранения (на Яндексе ещё и в облако), Game Ready и разметка геймплея.
- `js/ads.js` — реклама для Android (плагин `OneTouchAds`) и заглушка в браузере.
- `js/i18n.js` — русский и английский, язык выбирается автоматически.

## Оформление
- Одна сцена: стена, деревянный стол, свеча. Тень мягкая и слегка дрожит от огня, предметы объёмные с освещением, в луче летают пылинки.
- При совпадении контур вспыхивает и разлетаются искры.
- Каждые 15 уровней новая комната: Чердак, Детская, Театр, Мастерская.
- Анимация идёт ~30 кадров/с и останавливается, когда игра свёрнута.

## Звук
- `js/audio.js` — весь звук генерируется кодом (Web Audio), без файлов.
- Музыка: тихий эмбиент, у каждой комнаты свой лад; в Детской — музыкальная шкатулка.
- Атмосфера: треск свечи и фон комнаты (только на игровом экране).
- Отклик: шорох при вращении зависит от скорости, щелчки кнопок, тики ползунка каждые 5°, колокольчики при победе, звук подсказки.
- В меню отдельно «Звук» и «Музыка». Всё замолкает при сворачивании и во время рекламы.

## Рост сложности
- Уровни 1–7: один предмет, есть счётчик процентов совпадения.
- С 8-го: счётчик скрыт, подгонять надо на глаз.
- С 15-го: третья ось, ползунок «Наклон».
- 20–39: пары предметов, 40–60: тройки.
- Порог совпадения подбирается для каждого уровня так, чтобы допуск был 6° в начале и 3,5° в конце. Сложность растёт от формы, а не от пиксельной точности.

## Картинки для RuStore
Лежат в `store/rustore/`:
- `icon-512.png` — иконка 512×512, без прозрачности
- `screenshots/phone/1-5.jpg` — 5 скриншотов телефона 1080×1920 (до 3 МБ каждый)
- `background-1920x1080.png` — горизонтальная картинка с названием: превью для VK Видео и кадр для фонового видео карточки

Пересоздать: `python3 tools/promo/render_rustore.py` (нужны Playwright, Chrome и Pillow).

Видео в `store/rustore/video/` (27 с, 1080p, со звуком):
- `shadows-16x9.mp4` — горизонтальное, для VK Видео → поле «Видео» в RuStore, подходит и как фоновое
- `shadows-9x16.mp4` — вертикальное, публикуется в VK как клип

Пересоздать: `python3 tools/video/capture.py && python3 tools/video/render_art.py && python3 tools/video/compose.py` (нужны Playwright, Chrome, Pillow, numpy, ffmpeg).

## Уровень дня
- Каждый день новый уровень средней сложности (с наклоном, 1–3 предмета). 365 уровней в `js/daily-data.js`, по кругу.
- За первое прохождение за день: +1 бесплатная подсказка (без рекламы, копится до 5) и серия дней подряд. Пропуск дня сбрасывает серию.
- Пересоздать: `node tools/generate-daily.mjs`, проверить: `node tools/check-daily.mjs`.

## Аналитика (Яндекс Метрика)
- Номер счётчика вписывается в `js/config.js` (`METRIKA_ID`). Пока там 0, события только копятся локально: открой игру с `?stats=1`.
- Цели (создать в Метрике как «JavaScript-событие» с этими идентификаторами): `game_open`, `level_start`, `level_win`, `level_quit`, `hint`, `daily_start`, `daily_win`, `daily_quit`, `ad_rewarded`, `ad_interstitial`.
- У событий есть параметры: номер уровня, время, была ли подсказка. Параметры посетителя: `max_level` (докуда дошёл) и `daily_streak`.

## Реклама
- За награду: подсказка.
- Полноэкранная: каждый 3-й пройденный уровень, сразу после победы и до окна с кнопками.

## Перед релизом
- В `js/main.js` поставить `TEST_UNLOCK_ALL = false` (сейчас для теста открыты все уровни).

## Запуск и проверка
```
python3 -m http.server 8080          # открыть http://localhost:8080
                                     # ?unlock=1 открывает все уровни для теста
node tools/generate-levels.mjs       # пересоздать уровни (около 40 с)
node tools/check-levels.mjs          # проверка: решаемость, допуск, случайные победы
```

## Сборка APK
Проще всего — `build-apk.bat` (Windows): скачивает репозиторий в `D:\shadow-build`, ставит зависимости, создаёт Android-проект, при первом запуске делает ключ подписи (спросит пароль), собирает подписанный APK и кладёт его рядом с собой вместе с `build-log.txt` и копией ключа.

Вручную:
```
npm install
npx cap add android              # один раз
npm run sync-release             # игра с закрытыми уровнями + портрет, версия, реклама, иконки, подпись
cd android && gradlew assembleRelease
```
- `android-src/` — наш Android-код: `GameAdsPlugin.java` (Yandex Mobile Ads: межстраничная и с вознаграждением), иконки всех размеров, заставка.
- `scripts/setup-android.mjs` встраивает это в проект Capacitor и подключает подпись из `keystore.properties` (лежит вне git).
- `scripts/patch-android.mjs` — вертикальная ориентация и версия из `package.json` (1.2.3 → versionCode 10203). Перед каждым обновлением поднимай `version`.
- ID рекламных блоков — `js/config.js` (`AD_UNITS`).
- Ключ подписи (.jks) и пароль в репозиторий не кладём. Потеря ключа = нельзя выпускать обновления.
- Тексты карточки: `store/rustore/description.md`.
